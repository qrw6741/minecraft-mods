# Minecraft mods (1.20.1 Forge 47.4.28)

| Mod | Folder |
|---|---|
| Reaper's Arsenal - scythes, katanas, daggers, warhammers, spears, halberds | [`reapers-arsenal/`](reapers-arsenal) |
| Ashen Realms - RPG bosses and legendary weapons | [`ashen-realms/`](ashen-realms) |
| Ashen Expanse - Ashlands dimension, new ores, armor, mobs and the Ashen Tyrant (needs Ashen Realms) | [`ashen-expanse/`](ashen-expanse) |

Every push to `main` builds all mods with GitHub Actions and runs in-game smoke tests on a real Minecraft server
(every item is held, every mob is spawned, and Ashlands chunks are generated). Download the jars from **Releases**.
